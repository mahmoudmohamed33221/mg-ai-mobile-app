# MG.ai CODER — تطبيق أندرويد

مساعد برمجة مبني بـ Capacitor، والـ APK بيتبني تلقائيًا على GitHub Actions.

## الإعداد (مرة واحدة)

1. ارفع محتوى المجلد ده على الريبو (استبدل الملفات القديمة، **وخلّي مجلد `keystore/` مرفوع** — ده مفتاح التوقيع، لو اتمسح مش هتقدر تحدّث فوق النسخ القديمة).
2. خلّي الريبو **عام (Public)** عشان زرار التحديث جوه التطبيق يقدر يحمّل الـ APK.
3. من تبويب Actions شغّل `Build & Release Android APK` أو اعمل أي commit. أول بناء بيطلع Release اسمه `build-1`.
4. نزّل `MG-ai.apk` من صفحة Releases وثبّته. **أول مرة بس** لازم تمسح النسخة القديمة (لأنها كانت متوقّعة بمفتاح debug مختلف).
5. افتح التطبيق ← ⚙ الإعدادات:
   - مفتاح Gemini
   - GitHub Token (Fine-grained، على الريبو ده بس: Contents = Read and write، Actions = Read، Metadata = Read)
   - الريبو بالشكل `username/mg-ai-mobile-app`
   - فعّل «وضع المطوّر»، واضغط «اختبار الاتصال».

## الاستخدام اليومي

- اطلب من المساعد أي تعديل على التطبيق. هيقرا الكود، يجهّز التعديل، ويسألك قبل الرفع (تشوف الملفات اللي اتغيرت).
- بعد الرفع: بناء حوالي ٤–٦ دقايق، وبعدين بيظهر زرار ⬆ «تحديث». اضغطه، نزّل الملف، واضغط تثبيت. بيتثبت **فوق** النسخة الحالية ومحادثاتك وإعداداتك بتفضل.
- لو تعديل ضرّ بحاجة: الإعدادات ← «تراجع عن آخر تعديل»، أو Revert من GitHub.

## ضمانات الأمان

- `scripts/check-web.js` بيفحص الـ JavaScript قبل كل بناء. لو فيه syntax error البناء بيفشل ومفيش APK بيتنشر، فالنسخة اللي على موبايلك بتفضل شغالة.
- المساعد ممنوع يعدّل: `.github/` و `keystore/` و `scripts/` و `www/version.json`.
- كل APK بياخد رقم إصدار أعلى تلقائيًا (رقم البناء)، وده شرط أندرويد عشان التحديث يتثبت فوق القديم.
